# Fonts

Montserrat, Lora, and Alumni Sans Pinstripe, latin and latin-ext subsets as woff2, downloaded from Google Fonts on 2026-10-22. `warped.css` declares them with relative URLs, so they load from the CDN alongside it, or from a local copy in a site preview.
